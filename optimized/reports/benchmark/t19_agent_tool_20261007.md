## 契约

- Agent 只注册一个 `recommend` 工具，参数必须精确为 `{"request": <complete FixedRequest>}`。
- `FixedRequest` 与 `constraints` 都要求完整且无额外字段；缺字段、额外字段和类型错误返回 `INVALID_RECOMMENDATION_REQUEST`，不会进入 pipeline。
- planner system prompt 明确把 public request 当作数据，禁止使用 evaluator-only 字段。
- 每个计划在任何工具副作用前验证公开 `user_id` 和 `history_authorized`；结构化输入还必须逐字段保持不变。
- A 使用 `ALWAYS_AGENT`；O 与路由消融使用 `OURS_ROUTER`；`no_replanning` 固定为一次 planner、零次 replan。
- 工具成功只转发 fixed pipeline 的结构化结果，provenance 为 `ours:fixed_pipeline`；异常不暴露原始错误文本。
