# 四组准确率优先路线：验证协议

2026-10-12，用户授权真实 DeepSeek 调用，按账户余额停止；不设新的金额授权门槛。状态：实现/训练/评测尚未完成，NOT EVALUATED。

本协议在新训练、校准和正式评测前记录。不改 upstream、不覆盖旧预测或评分。四组是论文思想的小规模方法验证，不是 Rank-GRPO/OneRec 工业模型或权重复现。

## 固定组合及对照

- B0：实际微软 App + 原资源，沿用已验证运行配置。
- B1：当前 validated-20261011 LightGCN / RRF / O AgentLoop，匿名显式历史。
- C1：显式增量状态 + 来源确认目录硬过滤 + 最终验证；只有无效解析/证据冲突时才增加模型纠错请求，最多两次语义修复。独立验证只用公开输入、系统状态及公开目录。
- C2：C1 + 实际 SFT/策略梯度训练的小型状态决策策略，比较 SFT-only / RL；训练动作是如何合并当前解析与历史状态。不是对 DeepSeek 权重做 Rank-GRPO。
- C3：C2 + train-only 交互序列模型、文本/类型表示、协同/热门特征联合学习精排。固定权重/旧RRF作为对照；不预设神经融合优于旧模型。
- C4：受约束目录 ID 自回归生成 + 显式状态 + 实际 SFT / 策略梯度后训练。模型从现有目录和训练交互训练，不下载/冒用快手商品 token，不能称 OpenOneRec 直接迁移。比较 SFT-only / RL。

优先执行 C1、C2、C3、C4；正式评测同时运行 B0/B1。每组均必须有实际实现、运行和保留预测；不把未实现项或 fixture 当作完成。

## 任务与隔离

新固定任务：40 条目录条件、40 个匿名历史偏好用户、40 个两轮反馈用户，共 120 个任务 / 每系统 160 轮。用户与此前正式40用户和校准2用户不重叠；文本与年份/类型组合新增变化。不用新正式预测选超参。旧 MovieLens test 曾被项目历史研究使用，因此新用户子集不是全新数据集盲测，质量结论仍须标注 Previously Exposed Test。

仅公开消息、明确提到的历史电影及公开目录可以进入系统；原始用户 ID、未来目标和 evaluator 标签在独立私密文件，仅评分器可读。训练只读取 train；训练开发用户与本轮正式用户隔离。三个训练 seed：42、2024、2025；正式在线主对照 seed42，其余 seed 使用相同已记录解析离线重放，单独报告，不能当作三次完整在线评测。

新系统目录在预测前从既有公开 MovieLens10M 来源确认身份、年份与类型；只保留经过既有严格交叉核验确认的训练目录 ID。B0/B1 不改其目录/资源，评分规则同一份、冻结不变。目录修正/候选收缩是明确的系统贡献，不全归因到学习算法。不得向推荐器注入未来喜欢目标，不调用评分器来挑选运行时答案。

## 指标和计费

主指标仍为所有任务的严格 episode success；反馈要求两个轮次均通过。原定义包括身份、数量、所有正类型、年份、排除，不包含偏好命中。本轮可添加类型否定/上一轮结果排除标签，但保留共同原规则并记录扩展项，原端也受同一规则评分。

次指标：逐轮约束精度、Hit/Recall/NDCG@10（仅40偏好用户）、真实请求/输入输出token、原生工具调用、预热后任务延迟p50/p95。新组合与 B1、B0 均做配对 bootstrap 10,000次；四个组合对B1主指标另外报告多重比较校正的证据，不按最高点估计宣称胜出。工程成功和 statistically verified gain 分开。

DeepSeek deepseek-flash，非思考、temperature0、512输出token、网络零重试。真实请求前写意图、后写响应/usage，余额每20次刷新，HTTP402或余额不可用锁存停止。语义修复不是网络重试，全部费用和延迟计入。预算耗尽保留部分任务，不将未运行项计入完整结果或标DONE。总余额变化不是逐版本账单费用。

## 额外证据

来源对齐、状态继承、验证修复、RL、序列/学习精排消融，尽量利用已记录真实解析进行离线组件重放；重放指标明确标记不含在线解析随机性，零新增API不能伪称在线资源收益。模型训练曲线/优化步数/权重哈希，输入/源码/协议哈希，全部保存于忽略的 artifacts/comparison 新目录。

验收：关键回归测试、实际校准、冻结正式输入、所有6系统正式评测或余额不足、逐条离线重算和请求对账、最终效果/取舍报告。历史评测快照保持。没有证明提升时写 NO VERIFIED GAIN。

## 研究依据（本轮之前已联网核验）

- [约束感知生成重排，2026](https://arxiv.org/abs/2603.04227)：借鉴可行集合内选择，不搬用广告插入复杂度/最优性结论。
- [DisenCRS，2025](https://arxiv.org/abs/2504.17427)、[Re2A，2026](https://arxiv.org/abs/2609.18249)：偏好状态、当前重点与背景分离；我们的增量状态是适配。
- [Rank-GRPO，2025/2026](https://arxiv.org/abs/2510.20150)：推荐单位奖励与目录约束；本轮小策略训练不是论文 Rank-GRPO。
- [LLM2Rec，2025](https://arxiv.org/abs/2506.21579)、[CCFRec，2025](https://arxiv.org/abs/2503.12183)：联合语义/协同训练；现有文本特征不足以声称完整 LLM embedding 方法复现。
- [OpenOneRec，2025/2026](https://arxiv.org/abs/2512.24762)：目录 ID 生成和推荐导向后训练；本轮仅小模型方法验证。
