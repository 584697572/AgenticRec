# T09：LightGCN 稀疏传播、层数实验与真实评测

状态：**DONE（T09 单 seed 验收）**。本报告只对应规范 §7.1/T09 的独立 MovieLens1M 质量实验，不代表旧 checkpoint、旧相似度矩阵或论文原条件 A2 复现。完整机器结果与各 epoch 曲线见 [lightgcn_seed_42.json](lightgcn_seed_42.json)。

## 实现和来源

- 方法依据：[LightGCN 论文](https://arxiv.org/abs/2002.02126)与[作者 PyTorch 参考实现固定提交 `947ca2b3b1d2d3545b114145710cb06c4e57b3d2`](https://github.com/gusye1234/LightGCN-PyTorch/blob/947ca2b3b1d2d3545b114145710cb06c4e57b3d2/code/model.py)。仅查询参考仓库 HEAD、阅读模型源码，未克隆或复制实现。这里自行实现，并沿用本项目 T06/T07 数据与 ID 契约。
- 从经 SHA 校验的 `train_positive.parquet` 构造用户—电影无向二部图，462,887 条训练期正反馈形成 925,774 个对称稀疏非零项；节点数 5,351+3,469=8,820，零度节点 0。图使用 float32 COO，`A_norm = D^(-1/2) A D^(-1/2)`，没有自环、特征变换、非线性层或稠密全图。
- 传播 `E^(l+1)=A_norm E^l`；最终向量是 `E^0...E^L` 的均匀平均。用户与电影最终向量点积给出排名分数。BPR 的 `mean(softplus(s_neg-s_pos))` 使用传播后的向量，正则项只施于当前三元组的 ego embedding，按 batch 均值归一化；这与作者参考实现的正则位置一致。
- 与 T08 同用训练期 462,887 条正边及仅从训练期已评分历史构造的负采样排除集合；每个 epoch 遍历所有正边一次。层数 1/2/3 同一 seed、初始维度32、Adam lr0.001、batch32768、λ=1e-4，最多8 epoch、patience2，均以 valid NDCG@10 选 checkpoint。只在三层全部完成并依据 valid 确定层数后读取 test。配置见 [lightgcn.yaml](../../AgenticRec/configs/lightgcn.yaml)。
- checkpoint 保存完整模型配置，以及 T06 数据 manifest、ID 映射、split、训练正边文件、配置、训练代码 SHA 与 Python/PyTorch/PyArrow 版本；加载时严格校验。私有三个模型留在 `artifacts/models/lightgcn/`，不公开数据或权重。

## 数值与数据校验

小图训练边为 `(u1,i1),(u1,i2),(u2,i2)`。程序构造的归一化邻接对应 `u1-i1=1/√2`、`u1-i2=1/2`、`u2-i2=1/√2`，不存在预留的 `u2-i1` 边。对固定二维初始向量，第 1/2 层 `sparse.mm` 与独立稠密手算均在绝对误差 **≤1e-6（CPU float32）** 内；三层聚合实测包含第 0 层。梯度、合法 Top-K、checkpoint 完全重载与错误 ID/训练正边哈希拒绝测试通过。

真实图由训练期正边构造，验证和测试交互仅在单独的审计测试中读取；两者与训练正边的交互键重叠数均为 **0**。训练文件 SHA 与 T06 manifest 一致，图非零项数量恰为正边数两倍。

## 真实结果与局限

| 层数 | valid 最优 epoch | valid NDCG@10 | test 使用情况 |
|---:|---:|---:|---|
| 1 | 8 | 0.118816 | 未读取，不用于选择 |
| 2 | 7 | 0.120692 | 未读取，不用于选择 |
| 3 | 7 | **0.121865** | valid 选中后读取一次 |

所有模型同用 3,469 个训练期候选电影、训练期所有已评分物品过滤、相同 5,351 名 warm 用户与冻结相关集合；test 主均值含有相关物品的 954 名用户，另 4,397 人单独报告无相关项。

| test 模型 | Recall@10 | Hit@10 | MRR@10 | NDCG@10 | 失败 |
|---|---:|---:|---:|---:|---:|
| Random（T08 同 seed） | 0.002354 | 0.120545 | 0.039581 | 0.014081 | 0 |
| Popularity（T08 同数据） | 0.053370 | 0.617400 | 0.340002 | **0.195795** | 0 |
| BPR-MF（T08 同 seed） | 0.051520 | 0.611111 | 0.331544 | 0.192089 | 0 |

LightGCN 的单 seed test NDCG@10 比本轮 BPR-MF 高约 0.001957，但比 Popularity 低约 0.001748；**未证明超过最强简单基线，也未证明统计显著提升**。上限 8 epoch 时 1 层的 valid 曲线仍在上升，属于当前配置的训练预算限制。最终3 seeds 与进一步消融尚未完成；旧 A1 文本命中结果不能与这里的 ID 排序指标混算。

在 `AgenticRec/` 执行 `python -m pytest tests/unit/test_lightgcn.py` 和 `python -m agenticrec.cli train --config configs/lightgcn.yaml --seed 42`。本沙箱 pytest 临时目录需加 `--basetemp D:/AgenticRec/reproduction/.runtime/pytest-t09`。专项 5 项、完整 41 项均通过，第二隔离环境的完整 41 项也通过；保留 PyTorch 缺少可选 NumPy 桥接和 TypedStorage 弃用提示。未下载新模型或数据包，无 LLM/API 请求。最终全量训练与评测约 149.902 秒（本机 CPU 4 线程），不是独立线上延迟。

首次运行发现 checkpoint 只存配置哈希与维度，未存完整配置；在本地忽略目录 `artifacts/models/lightgcn/pilot_metadata_v1/` 归档首次模型、结果与源码快照，再补齐序列化字段后按**完全相同的 seed/超参数**重跑。两次三个层数的 valid 指标及选中模型的 test 指标逐项相同，未根据 test 改配置。最终三个 checkpoint 的 SHA256 与机器报告一致；重新加载后分别重算所有 valid 指标，与保存值一致。选中 checkpoint SHA256 为 `5d439abf641f3992a0c391917674f36d488bd49f47087adaf21422d66ff7679c`，其 test 指标重算也完全一致。匿名新用户没有图节点或训练出的 ego embedding，不能把文本偏好直接映射成已知用户 ID；规范 T10 需要独立 SessionScorer/冷启动路径。传播层数继续增加会让相邻节点表示趋同，过平滑风险应在后续层数消融中结合 valid 而非 test 判断。
