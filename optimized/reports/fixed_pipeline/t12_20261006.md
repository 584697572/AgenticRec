# T12 deterministic fixed recommendation baseline

**Status: PASS for T12 F-baseline acceptance.** `agenticrec.pipeline.FixedRecommendationPipeline` joins the T11 hard gate and three-route retrieval with the T10 known-user/anonymous scorers. It consumes a strict versioned JSON request and invokes no planner, LLM, network service or holdout evaluator.

The fixed sequence is: validate request → apply hard constraints → content/CF/popularity recall → RRF → known-user or anonymous scoring → deterministic rerank → apply the hard gate again → return evidence. Each recommendation contains its frozen model item ID, title, genres, year, personalized score, RRF score and the one-based rank contributed by every source that recalled it. Candidate counts and the selected `profile_source` are also returned. Raw scores from different recall methods are not added together; RRF combines route ranks, while the profile scorer determines the final order with RRF as a deterministic tie-break.

The CLI command is:

```powershell
agenticrec recommend --request configs/fixed_request.example.json
```

or, without activating the environment:

```powershell
& .\.venv-dev\Scripts\python.exe -m agenticrec.cli recommend --request configs/fixed_request.example.json
```

The request must be structured JSON. Free text is rejected as `INVALID_REQUEST`; the fixed baseline does not silently call a parser. A future natural-language parser must report and meter its LLM use separately. Missing model/data resources are reported as `PIPELINE_ERROR`, rather than mislabeling them as malformed user input.

Four real MovieLens1M scenarios were run over all 3,469 frozen candidates:

| Scenario | Status | Profile route | Fused | Returned | Result |
|---|---|---:|---:|---:|---|
| Authorized known user | `OK` | `known_user` | 192 | 5 | Complete metadata/source/score evidence |
| Anonymous liked seed | `OK` | `cold_start` | 200 | 5 | Seed excluded from output; complete evidence |
| Explicit item exclusion | `OK` | `fallback_popularity` | 100 | 10 | Excluded item absent after final rerank |
| Impossible year range | `NO_FEASIBLE_ITEMS` | `fallback_popularity` | 0 | 0 | Conditions retained; no padding or relaxation |

The smoke script also launched the actual CLI in a subprocess whose environment omitted API credentials. It returned three valid recommendations with `planner=not_invoked`, `llm_requests=0`, and `remote_api_requests=0`. No valid/test labels were loaded. The ID/title/score-bearing responses remain in ignored `artifacts/fixed_pipeline/t12_trace_20261006.json`; the public [`t12_20261006.json`](t12_20261006.json) contains counts, statuses and its SHA256. Two consecutive runs produced the same private trace hash.

Results: **6/6** focused integration tests and **61/61** full tests in each independent Python 3.11 environment. The initial focused run had five passing cases and one setup error because pytest tried to use inaccessible `C:\Windows\Temp`; assigning a project-local `--basetemp` produced the complete passing run.

Structured genre/year requests, authorized identity routing, candidate fusion, scoring, exclusions and evidence formatting no longer need an Agent. An Agent may become useful for ambiguous natural language, contradictory multi-turn updates or deciding which missing fact to clarify. T12 does not evaluate recommendation quality or claim an improvement; those comparisons remain for the frozen evaluation/benchmark tasks. The separate T04 original-resource ID/license blocker is unchanged.
