# 微软原资源运行版与指定优化版本：首次真实同题对比

日期：2026-10-12。正式执行 COMPLETED，日志重算 VERIFIED。结论：资源消耗明显下降，推荐命中有正向点估计，但没有证明质量或整任务成功率稳定提升。

## Completed

执行原App与个人优化真实流水线，60个相同公开输入案例×两个版本，共120次案例执行、160轮任务。20个条件推荐、20个匿名历史偏好推荐、20个两轮反馈；没有使用U1替代原版。正式228次真实HTTP200，原端148次，优化端80次。加上校准15次，本轮共243次生成请求，无网络重试、无新增实验模型训练或下载。

指定优化版本为validated-20261011 LightGCN seed42 + RRF + O AgentLoop，输入匿名显式5部历史电影。原端为固定源码+原资源+既有zero-demo/无reflection兼容运行配置。两边DeepSeek deepseek-flash、temperature0、非思考、实际512输出token；具体配置见[冻结协议](original_comparison_protocol_20261012.md)。该对照不是作者论文原条件。

严格成功要求每轮均给出10部、电影身份可确认、全部指定年份/类型/已看排除条件满足；两轮任务两轮都通过。约束精度先计算每轮正确结果项比例，再在80轮平均，空/未解析轮为0；不是所有输出项加权的micro precision。一部不满足或身份无法确认就可能让整任务失败，所以约束精度高不等于整任务成功率高。

Hit/Recall/NDCG只在20个session_quality用户上计算，包括执行/解析失败，另外20个反馈用户不重复计入该质量分母。相关目标来自历史已暴露1M测试，未传到系统；输入仅最近5个共同训练期正反馈电影，故不能与以前954暖用户、完整历史的约65% Hit@10横比。

## Findings

两边各20例的成功数：

| 任务类别 | 原版 | 优化版 |
|---|---:|---:|
| 条件推荐 | 10/20 | 11/20 |
| 历史偏好推荐的完整交付 | 5/20 | 6/20 |
| 两轮反馈，所有轮均通过 | 4/20 | 1/20 |

失败诊断按80轮计算，类别可重叠，不能相加作为独立失败总数：

| 诊断 | 原版 | 优化版 |
|---|---:|---:|
| 非OK轮 | 4 | 0 |
| 最终数量不正确的轮 | 12 | 0 |
| 有身份识别失败的轮 | 41 | 28 |
| 按10M标注，不满足类型的已识别结果项 | 43 | 29 |
| 不满足年份的已识别结果项 | 34 | 0 |
| 仍推荐输入中已看的结果项 | 3 | 0 |

身份识别失败不自动意味着虚构电影。优化端31个未确认结果项中23个显示`Raiders of the Lost Ark (1981)`；既有来源别名规则无法将该显示名唯一确认到统一10M身份。类型差异也有1M/10M标注不一致因素。严格成功率因此包含身份/元数据可验证性，不能把所有低分都归因于模型推荐错；真实整任务稳定改善仍未证明。

本批所有自然语言任务均走Agent路径，实际优化端每轮一次规划请求，未发生额外重规划。请求节省主要包含工具接口/提示缩短及原版保留总结LLM、优化版原生结构化交付的差异，不能将45.95%全部归因于路由，也不能用此批证明重规划收益。原端205次、优化端80次原生工具调用，接口粒度不同，不能称底层计算减少同等比例。

延迟采用单并发、交错版本顺序、模型预热后计时；仍有提供商缓存/时段影响，不是线上QPS或纯算法加速证据。原端模型加载约361.38秒，优化端流水线初始化约5.01秒，加载边界不同且准备阶段并行跑过测试，不比较冷启动速度。

原端148个响应中12个`finish_reason=length`，优化端80个均为`stop`。本批双方512输出预算对原长计划/回答确有截断影响，所有截断保留；不能把这种运行预算条件下的原端成绩称为原项目最大能力。

匿名优化路径主要使用训练期ItemCF/内容/热门融合，未提供训练用户ID；虽然加载GCN权重，本批不是LightGCN已知用户向量对SASRec的纯模型实验。原权重训练集/行语义仍未确认，质量点估计只能作当前系统描述性对比，不能声称无泄漏算法收益或超越原论文。
