Python 3.7+ 字典保证不同键的插入顺序，但同一个键仍只有一个槽位。再次写入相同工具名会替换旧值，不会产生第二个步骤。因此“dict 保序”不能修复重复工具调用。

## 新执行语义

- `parse_plan` 只接受由精确 `step_id/tool_name/arguments` 对象构成的非空列表，不把列表转成以工具名为键的字典。
- `PlanExecutor` 先验证完整计划，再执行任何工具；未知工具、重复 `step_id`、缺失/多余/错误类型参数均 fail closed。
- 工具注册表使用唯一工具名字典，但计划本身始终是 `PlanStep[]`，所以同一注册工具可按列表位置重复执行。
- 每一步保留位置、`step_id`、工具名、原参数、结构化 `ToolResult` 和耗时。失败或异常停止后续步骤并保留失败 trace；异常消息不写入公开结果。
- 不做上游的子串工具匹配或自动补 Map；这些行为会隐藏计划错误。后续 Agent 必须显式生成合法步骤。

实际离线轨迹为 `lookup(first-query) → lookup(second-query) → map(limit=5)`，三步及参数逐项保留。
