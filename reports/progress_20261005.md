## Findings

ReDial 数据由原作者声明 [CC BY 4.0](https://redialdata.github.io/website/datasheet.html)，引用 Li et al., *Towards Deep Conversational Recommendations*, NeurIPS 2018。实际输入来自 [固定 UniCRS test 文件](https://github.com/RUCAIBox/UniCRS/blob/f7d8f95104d6eba5371cfa845b243057a632079e/data/redial/test_data_dbpedia_raw.jsonl)。UniCRS 代码 MIT 不替代电影资源/权重授权。只取得 test 和小型许可/来源元数据，未下载约 60 MB train、valid 或 DBpedia。

原 notebook 的 `movie_map` 对重名电影使用带符号日期差的最小值，可能优先更早的翻拍版。本轮保留这一行为，只将局部副本的整数年份转换为该年 1 月 1 日供比较，不宣称知道真实上映月日。源码、app 的年份列和资源原件均未改。`process_conv` 的 set 顺序也保留，固定 seed 仅使本地产物可重复。因此这是 **A1 重建的原预处理输入**，与作者原始 50 条文件的等价性 **NOT VERIFIED**，不是自造对话，也不是 A2。

下载首次长度校验失败，未接受为数据；改用明确 Range 并流式读取后 Git blob/SHA 通过。该次失败字节数未保存，不虚构累计下载量。审计脚本首次因 NumPy int32 无法 JSON 序列化失败，残缺文件保留；修正仅影响审计输出，重跑取得 42 个真实上游 dtype 异常。uv 曾尝试不可写的用户缓存；显式指定项目内 UV_CACHE_DIR 后依赖检查通过。没有调整全局权限。
