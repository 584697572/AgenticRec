# T08：Random、Popularity、BPR-MF 实测

状态：**DONE（T08 单 seed 验收）**。范围是规范 §6.3/§7.1/T08 定义的独立 MovieLens1M 质量实验，属于 B/upstream_rebuilt，不是旧 checkpoint 或论文 A2 复现。逐项机器可读结果与训练曲线见 [seed_42.json](seed_42.json)。

## 固定协议与实现

- 官方 MovieLens1M 的 T06 全局时间切分、训练期 ID 映射与 T07 valid/test cohort 均未改；5,351 个训练期 warm 用户、3,469 个训练期候选电影、462,887 条 warm 用户训练期正反馈。只对未来窗口里有 warm 正反馈的用户计算主均值：valid 481 人，test 954 人。其余 4,870/4,397 人另报无相关项，不偷偷进入或退出模型间分母。
- 三模型同用固定候选全集、剔除训练期该用户**所有**已评分电影、K=10、同一相关集合和 ID 升序破并列。Random 每用户从合法候选以固定 seed 不放回采样；Popularity 由 462,887 条训练期正反馈计数并稳定排序；它不同于上游的加权抽样基线。
- BPR-MF 是 32 维用户/物品 embedding，打分 `p_u · q_i`。每个 batch 的目标为 `mean(softplus(s(u,j)-s(u,i))) + λ × mean((||p_u||²+||q_i||²+||q_j||²)/2)`，`λ=1e-4`。负样本从训练期候选均匀抽取，排除该用户训练期所有已评分物品；不读 valid/test 构造排除表。未来正反馈可能被抽成未观察负样本，这是该离线隐式反馈方法的限制。
- 配置在 [bpr.yaml](../../AgenticRec/configs/bpr.yaml) 冻结：Adam，lr=0.001，batch=2048，最多 8 epoch，valid NDCG@10 早停 patience=2，seed=42，CPU 4 线程。只用 valid NDCG@10 选 best epoch；test 在 best checkpoint 保存与重载后才读取。没有用 test 调参，也没有 train+valid 重训。

## 真实结果

| Split / 模型 | Recall@10 | Hit@10 | MRR@10 | NDCG@10 | 有相关项用户 | 失败 |
|---|---:|---:|---:|---:|---:|---:|
| valid Random | 0.004463 | 0.076923 | 0.015229 | 0.007383 | 481 | 0 |
| valid Popularity | 0.047249 | 0.413721 | 0.216370 | 0.122907 | 481 | 0 |
| valid BPR-MF | 0.045975 | 0.407484 | 0.203745 | 0.120395 | 481 | 0 |
| test Random | 0.002354 | 0.120545 | 0.039581 | 0.014081 | 954 | 0 |
| test Popularity | 0.053370 | 0.617400 | 0.340002 | 0.195795 | 954 | 0 |
| test BPR-MF | 0.051520 | 0.611111 | 0.331544 | 0.192089 | 954 | 0 |

训练均值 loss 在 epoch 1/2/3 分别为 0.640619 / 0.355550 / 0.293884；对应 valid NDCG@10 为 0.120395 / 0.119763 / 0.119366。因此 best epoch=1，epoch 3 触发早停。单 seed BPR-MF **没有超过** Popularity：test NDCG@10 低约 0.003705。此结果不能宣称算法提升，亦不能与旧 A1 文本 hit 的 0/45 横向混算。
